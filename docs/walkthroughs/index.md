# 手动检索操作演练

[全书导航](../atlas/index.md) · [通用 SOP](../atlas/master-sop.md)

三组演练展示“如何组织任务、执行查询、处理结果、填写成果”。任务事实均为教学设定。流程中的查询式是执行建议；没有将它们写成已在平台实测的命中记录。真实执行时，以实际页面、取得原文和查询时间填写日志。

| 演练 | 训练重点 | 配套 SOP |
|---|---|---|
| [跨越民法典施行时间的合同问题](historical-law.md) | 分离事实时间、文本版本与时间效力判断 | [规范](../atlas/sops/norms.md) |
| [客户名单争议的类案比较](case-comparison.md) | 拆争点、保留相反材料、解释事实差异 | [案例](../atlas/sops/cases.md) |
| [12309公开资料与本人案件服务分流](procuratorate.md) | 识别公开检索、身份服务和办理任务 | [检察](../atlas/sops/procuratorate.md) |

先完成其中一组，再替换为自己的题目。评价标准是他人能否根据日志复查你的过程，能否看出哪些判断已获支持、哪些仍需材料。

## 读图方法

- 矩形是动作或产物，菱形是必须回答的问题；箭头标签是分流条件。
- 一个节点完成后留下记录，再进入下一步。没有证据回答判断节点时，标记“待核”，按补查路径处理。
- “未检出”“无法访问”“无权限”“仅摘要”分别记录；检索终止可以形成带未解决事项的阶段成果。
- 决策树组织检索过程。法律适用、证据评价与争议结论在原文比较后另行论证。

# AI时代法律文献检索指北

检索方法 · 资源导航 · 核验与引用

**编者：余客｜第一版 v1.0｜2026年10月｜76页**

面向法律学习、学术研究与实务资料查找的中文法律检索手册，以中国内地法律检索为主，兼及港澳台地区、主要外国法域与国际资料。

## 内容目录

1. 检索流程与工具选择
2. 法律法规与政策文件
3. 司法案例与法院服务
4. 检察与公共法律服务
5. 学术文献与研究资料
6. 主体与交易信息核查
7. 专项资源检索
8. 域外法与国际资料
9. 检索任务示范
10. 检索成果与资料管理
11. 开放项目与延伸阅读

另附编写说明、资料性质与核验原则及来源说明。检察与公共法律服务部分包含12309中国检察网、12348中国法律服务网等渠道。

## 使用方法

初学者可从第一至三章开始；开展具体任务时，按目录查找专题资源；第九章提供检索任务示范，第十章提供记录与报告模板。

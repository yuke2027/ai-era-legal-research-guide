# AI时代法律文献检索指北

**编者：余客｜v1.1 手动检索图谱版**

在答案越来越容易获得的时代，亲自寻找和审查依据。

本手册从手动检索出发，介绍如何进入数据库、组织检索词、阅读原始文献、比较不同材料，并留下可复查的记录。“AI时代”是本书的写作背景；读者独立找到依据、形成判断的能力，是本书希望交付的成果。
